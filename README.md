# GPG Clipboard

**GPG Clipboard Bridge** gets text you copy inside **Google Play Games for PC** (for example Clash of Clans →
Data Export → **Copy to clipboard**) onto the Windows clipboard, so you can paste it into Discord.

**[Download GPGClipboardBridge-Setup.exe](https://github.com/Gr1m0305/GPG-Clipboard/releases/latest/download/GPGClipboardBridge-Setup.exe)**
(Windows 10/11). Run it, click **Yes**, and it starts by itself every time you sign in. If Windows says
"Windows protected your PC", click **More info → Run anyway** (the exe is not code-signed).

Full instructions, troubleshooting and how it works: [gpg-clipboard-bridge/README.md](gpg-clipboard-bridge/README.md).
